# Anime Tracker — Backend

API REST para una plataforma de seguimiento y reseñas de anime.

## Descripción

Este repositorio contiene el desarrollo del **backend y la API REST** del proyecto Anime Tracker.

La API permite gestionar usuarios, anime, seguimiento personal, progreso, puntuaciones, reseñas y favoritos. También proporciona consultas y estadísticas generales sobre los anime.

## Tecnologías

- Node.js
- Express.js
- MongoDB
- Mongoose

## Estructura

El backend se encarga de:

- Gestión de usuarios y autenticación.
- Gestión de anime.
- Seguimiento y progreso de los usuarios.
- Puntuaciones y reseñas.
- Favoritos e historial.
- Búsquedas, filtros y estadísticas.
- Exposición de endpoints REST.

## Proyecto

El frontend se desarrolla en un repositorio independiente y se comunica con esta API mediante peticiones HTTP y respuestas en formato JSON.
